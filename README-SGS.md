# 三国杀 · 十周年单机研习

基于 [无名杀](https://github.com/libnoname/noname) 的本地单机 AI 游戏，提供按武将包浏览的选将大厅、完整技能阅读、姓名/技能/术语搜索、年份筛选、收藏与最近使用、暂停设置、本地战绩和问题报告，以及三人斗地主、四人 2v2 和多人身份军争对局。

## 现在怎么玩

首次克隆后，请先安装Node.js 22与pnpm，在项目目录运行 `pnpm --filter noname... --filter . install --ignore-scripts`。然后双击 `启动游戏.cmd`，浏览器访问终端显示的 `http://127.0.0.1:8081/sgs.html`。画像、卡牌、武将语音和受击音效已随源码提供，无需重新下载素材。

1. 选择武将，阅读右侧技能。
2. 选择玩法：斗地主可自选地主或农民；2v2中你在四号位，与一号位同队；多人身份局可选随机或指定身份。
3. 点击“整装出征”。其他角色由 AI 控制。
4. 发完起始手牌后，可点击“换一手”反复重抽；满意后点击“开始对局”，也可直接保留原手牌开局。
5. 点击手牌与目标，再点击确定；技能出现时依提示选择。可以结束回合、托管或返回选将。

桌面大厅采用暖棕顶栏与浅米色纸面，保留对局设置、武将列表、画像与技能三栏。1280×720下可完整显示两排武将，出战入口固定可见，长技能独立滚动。“最近使用”保留最近确认出战的8个武将版本，浏览或收藏不会计入；同名的不同包版本分别记录。窄屏大厅仍可访问设置与出战入口；手机竖屏牌桌未作完整适配。

默认按一将成名、限定专属、群英荟萃、星河璀璨、谋包、威包浏览，一将成名优先。神将、祈福将与武庙将归入限定专属，许劭（也可搜索“许绍”）归入群英荟萃。“隐藏老武将”会隐藏已有依据属于2020年及以前的版本，保留2021年起的新将/新版本；年份未核实的继续保留并标注，开关会保存。势力、原始包与其他版本移至“更多筛选”。这只筛选大厅列表，不删除武将或更改原生AI将池；已选出战武将会保留并在不符合筛选时提示。详细依据见 [武将包与年份筛选](docs/sgs-roster-packs.md)。

武将卡与详情显示官方十分制评分，列表支持“评分从高到低”“评分从低到高”。默认采用综合分；在“更多筛选 → 评分口径”可改为地主、农民、2v2先后手或身份分项，点击详情中的分数可查看全部分项。评分来自2026-10-01官方客户端数据快照，当前匹配681个武将版本；常用范围另外105个版本显示“评分待收录”，升序与降序均置后。排序与口径会保存，默认顺序可恢复原分包或最近使用顺序。数据与版本匹配依据见 [官方评分说明](docs/sgs-official-ratings.md)。

确认、取消、开局换牌与开始按钮采用更大的点击区域。选择杀、顺手牵羊、过河拆桥、决斗等单目标牌或简单单牌转化时，如果原生规则判定必须选择一个目标，且只有一名其他角色合法，会自动选中该角色；仍需手动点击确定才出牌。距离、装备和技能限制沿用原生规则。多个合法目标保留手选，手动取消目标后不会被自动选回；多牌技能、复杂选择和可选多目标的牌仍按原生流程操作。

出牌阶段选中铁索连环后，操作区会直接出现“重铸此牌”。点击后自动保留这张铁索进入原生重铸选择，再点“确定”才弃置并摸牌，无需先点技能再找牌。也可直接选择角色，照常使用铁索连环；重铸是否合法仍由原生规则判定。

青龙偃月刀追杀时，选中追加的杀会预选刚才闪避的唯一合法目标并显示“确定”，仍由你确认是否出杀。追杀不计入出牌阶段杀的次数，沿用原生规则；多目标等特殊选择仍需手动操作。

普通单牌选择中，选中一张后可直接点击另一张可用手牌切换，旧目标会清除并重新判断新牌的合法目标，仍需手动确定。点击当前不能使用的牌会保留原选择。制衡、弃牌等多选操作仍可连续选择多张牌。

牌桌会用文字标出真实的连环、翻面和护甲状态，小窗口也保留选牌/确认提示。“武将说明”可选择场上明置角色查看技能，长说明在窗口内滚动；“对局记录”可搜索最近300条公开记录，并通过返回按钮或Esc回到原选择。“操作帮助”提供当前玩法目标、选牌流程及状态说明。大厅会显示当前筛选条件，可逐项清除，并提醒已选出战武将是否在筛选结果中。

开局换牌适用于斗地主、四人2v2和身份局，仅更换自己的整手起始牌。原手牌回到牌堆，再抽取相同张数，AI手牌保持不变；界面显示已换次数。确认开局后关闭换牌入口，按原顺序开始回合。四人四号位的五张起手牌保持五张；地主的跋扈和正常回合摸牌在换牌结束后进行。

对局采用暖棕龙纹背景、44px单层深棕顶栏与木色切角按钮。本方武将位于右下，装备与技能在旁；短手牌居中，较多手牌向左扩展并保留原生收拢与滚动。顶部显示玩法、回合、牌堆、轮数与局时；手牌上方保留原生出牌与技能提示，已移除额外的操作类型、已选数量及说明状态栏。说明、公开记录、帮助、问题报告与重开集中在“牌桌工具”。确认、取消和开局主要按钮至少126×50像素。

顶部可直接暂停、托管或打开便捷设置。暂停和设置保留当前选牌、目标与原生弹窗，关闭设置只释放它自身的暂停；若另有暂停，仍需继续对局。局时不计暂停时间。后台自动暂停默认开启，离开页面后应暂停，返回需手动点击“继续对局”；实际后台切换的浏览器验收仍待完成，见[客户端验证记录](docs/sgs-client-experience-validation.md)。便捷设置提供AI行动速度、声音、三路音量、后台暂停和减少动态效果；系统的减少动态效果偏好也会生效。

右下角人物与手牌之间提供常驻“整理手牌”按钮，位于装备栏下方，使用原引擎排序规则；也可用键盘聚焦后按回车操作。整理保留已选卡牌，不消耗手牌。

斗地主为一名地主对两名农民：地主先手，体力及上限各加一。原生“跋扈”在准备阶段摸一张牌，并让出牌阶段出杀次数加一（通常为两次）；十周年版“飞扬”可在判定阶段弃两张手牌，移除自己判定区所有牌。地主击败两名农民获胜，农民击败地主获胜。沿用引擎的特殊武将初始化例外、队友手牌查看和农民遗产结算。

红桃、方块使用红色花色与点数。选中“杀”时，原引擎判定可攻击的目标保持深色并标注“可杀”，不可选目标淡化；已选目标突出显示，取消后恢复。武器、坐骑和技能的距离修正由原引擎处理。

选择手牌时，当前可用的牌保持明亮并有清晰投影，不可用的牌明显压暗，已选牌显示金色边框。可以直接换选的其他合法牌仍保持明亮。发动技能或实际出牌后，明暗会随原生合法性更新；开局换牌等非选牌阶段不压暗手牌。

手牌采用参考图中的经典布局：左上点数、其下花色、右上牌名、下方插画。出牌、摸牌或整理时复用原卡牌节点，整张牌平滑补位；点数、花色、牌名和图案保持相对位置，不再各自跳动或淡入淡出。手牌栏从左侧开始排列，并为右侧装备留出间距。

普通杀保留经典武者插画；雷杀、火杀改用三国杀官网经典牌面中的武者插画及雷纹、火纹字样，去掉之前错用的天雷/烈火图。官网原图原样本地保存，用固定CSS取景显示，不生成或重绘图片；花色点数始终来自实际卡牌。来源见 `docs/sgs-card-art.md`。队友小牌仍以文字和配色区分属性。

2v2 一号位先手，击败敌方两名角色获胜；沿用原引擎的四号位保护（起始手牌加一、获得飞扬），其余三人均由 AI 控制。青色席位是我方，红色席位是敌方，文字同时标明队伍。

2v2 队友和斗地主农民队友的当前手牌默认显示在头像旁，保留牌名、属性、花色与点数；摸牌、出牌、弃牌后自动刷新，牌多可滚动。空手显示“暂无手牌”，队友阵亡后收起。仅展示原引擎允许互看的队友手牌。

所有单机对局均已禁用木牛流马，重新开局生效。

非装备牌出牌、响应时播放本地语音；使用装备、选牌或取消不会播放报牌语音。威董卓、神庞统、神钟会、新杀神孙权、新杀谋荀彧、新杀谋曹昂、新杀谋邓艾、威公孙瓒和威马腾有本地技能与阵亡配音，含谋荀彧转换形态，共58条约7.20 MiB，按原生事件触发。卡牌报音与武将台词分开排队，可以同时播放且互不等待；同类语音保持顺序。便捷设置分别调整卡牌、武将与受击音量，默认均为100%；顶部“声音”按钮统一开关，静音后不会积压重播。首次点击牌桌后解锁浏览器声音，设置保存在本机。未收录武将配音及背景音乐保持静音。来源与验证见 `docs/sgs-card-audio.md`、`docs/sgs-character-audio.md`。

武将实际受伤时播放受击音效：普通、火焰、雷电、冰冻伤害分别有不同声音，1点使用普通受击、2点及以上使用重击。酒杀通常造成2点伤害并播放重击声；若被减伤至1点，则按最终伤害播放。护甲承伤另有对应音效。受击声即时播放，不等待武将台词排队；被闪避、取消、减至零或仅失去体力时不会误播。来源见 `docs/sgs-damage-audio.md`。

回合、合法目标、实际伤害和阵亡有短暂视觉反馈，取消、闪避或被防止的伤害不会显示命中；减少动态效果时保留静态操作提示。

原生引擎判定结束后，结算显示胜负、身份、轮数、扣除暂停的时长，以及造成伤害、受到伤害、获得牌、使用牌和击杀数，可打开原生详情对照。“再来一局”保留自己的武将版本、模式、实际身份与当前速度，重新随机其他武将和牌局。提前退出或重开不会生成胜负记录，也不支持关闭页面后续玩。

大厅“本地战绩”保留最近50局真实结算，可查看详情并按该局配置重新开局。设置、收藏、最近使用和战绩只保存在当前浏览器；存储不可用时显示未保存提示，仍可在当前页面游玩。名册或头像索引加载失败时提供重试与返回入口；缺少已打包声音时提示相应类别静音或跳过该段，不阻断对局。只要本地服务运行，游戏不需要账号或远程 AI 服务。首次打开会看到上游许可证提示。

## 覆盖情况

锁定 Noname 1.11.7 / `7fcf23ed54d8a7ce2b49ae2c15a054123891a52a`：

- 总计 **2,563 个武将版本**，26 个包；不同版本不合并。
- 原始版本分类中十周年专属包 **451 个**、通用经典包 **165 个**。当前默认“常用武将包”另纳入新一将成名、界限突破等目标版本，共 **786 个**可见条目；显示分组与原始版本分类分别保留。
- 其余 552 个混合/待核验、1,395 个其他版本单独筛选，不计作十周年已完成。
- 技能沿用真实引擎实现。源码解析与实际行为验证分别记录；**尚未完成官方全量名单与所有技能的一致性核验**。
- 代表技能实际运行记录见 `docs/sgs-validation.md`；机器清单见 `docs/sgs-coverage.json`。

当前版本在选将页和对局使用默认192×256的本地WebP头像，单图最多8KiB，全部画像不超过20MiB；不能重新取得原图的条目保留已验证旧图并记录原因。使用现成上游/网络图片，不使用生成图片；少数新版本借用同人物画像，三个测试武将使用经用户确认的公开测试剪影并标注。转换形态优先使用已有的对应本地画像，没有单独收录时沿用本体画像，原生形态ID和语音别名保留。来源见 `docs/sgs-portraits.md`。复杂武将/技能组合仍可能有上游差异。

本轮暖棕改版通过214项Node回归测试、3项画像维护测试及Node22/pnpm生产构建。2563个武将版本共用2491张本地画像，总计15.84MiB，全部为192×256且每张不超过8KiB。四档桌面尺寸与390px大厅/弹窗已作浏览器检查；斗地主两种身份、2v2及多人身份的开局、选牌、响应和复杂选择沿用真实引擎，并完成2v2与八人身份的自然结算。详细截图和证据见[暖棕改版验收记录](docs/sgs-warm-ui-validation.md)。旧MAT-07、UX-09的真实后台切换验收和US-006仍保持未完成；这些检查不代表全部官方武将或技能均已验证。

## 技能阅读与问题报告

选将详情提供“完整阅读技能”，可展开相关技能、卡牌和术语细则，并查看锁定上游版本的文本来源。此前常用名单中60位武将缺失的63项初始技能正文已经补齐；例如神黄忠“裂穹”的击伤四项和天冲均可在开局前阅读。这里只展示初始规则，局内变化仍以原生实时说明为准。文本提取不会执行武将脚本，也不代表技能行为已与官方逐项核验。

点击武将后保留原卡片与键盘焦点；删除筛选条件后，焦点移到相邻条件，全部清除后回到搜索框。中文组合输入完成后才更新搜索结果。

单条声音下载和解码合计超过8秒时跳过该条，后续同类语音继续播放；卡牌、武将及受击通道保持独立。静音或离开牌局会取消尚未完成的声音载入，迟到的声音不补播。

“牌桌工具 → 问题报告”可以手动下载JSON文件，包含客户端/上游版本、玩法、自己的出战武将、当前操作提示、最多20条错误摘要与300条原生公开记录。报告不自动上传，不收集原生事件对象、隐藏身份、手牌或牌堆快照。若局内出现未处理异常，会暂停并提供问题报告、同配置重开和返回点将台；未知异常不强行继续结算，提前离开不计败局。

设置、技能、评分、战绩、公开记录、报告与结算统一为纸色阅读面板，长内容独立滚动，底部操作保持可达。从SGS工具菜单打开的原生介绍以正常字号显示，保留原生关闭与暂停行为。可靠性功能的原始证据见[可靠性验证记录](docs/sgs-reliability-validation.md)。

## 开发与构建

环境：Node.js 22.12 或更高、pnpm 9 或更高。

```powershell
pnpm --filter noname... --filter . install --ignore-scripts
node scripts/sgs/dev.mjs
node scripts/sgs/build-catalog.mjs
node scripts/sgs/build-lobby.mjs
# 仅重建头像时需要 Python 3 + Pillow；游玩和常规构建不需要
node scripts/sgs/prepare-portraits.mjs
python scripts/sgs/build-portraits.py --download
node --test tests/sgs/*.test.mjs
node scripts/sgs/build.mjs
node scripts/sgs/serve.mjs
```

开发和生产服务默认都使用 8081 端口，请只运行一个；生产预览可以用 `$env:PORT='8083'` 后启动。服务只监听本机，资源接口只读。

# PRD: 三国杀十周年 · 单机研习版

## Introduction

在无名杀开源引擎上实现可在本机浏览器游玩的三国杀十周年单机游戏。最终目标为十周年全部武将及其可执行技能，分批实现、分批核验；不能将资料收录等同于规则验证完成。

## References

- 用户于 2026-10-03 明确：全量十周年武将与技能；只要单机 AI；同意复用 GPL-3.0 无名杀引擎并保留源码署名。
- 上游：https://github.com/libnoname/noname ，锁定提交 `7fcf23ed54d8a7ce2b49ae2c15a054123891a52a`（核心版本 1.11.7）。
- 官方公告 https://www.sanguosha.com/news/20231215_3585_1312 （谋周瑜、曹轶）；https://sanguosha.com/news/20231222_5521_1916 （谋鲁肃）；https://www.sanguosha.com/news/20221223_8364_1717 （神张飞）。
- `apps/core/character/` 为武将/技能实现来源；`apps/core/mode/identity.js` 为身份局来源。
- `docs/how-to-start.md`、`apps/core/noname/entry.ts`、`apps/core/vite.config.ts`、`LICENSE`。

## Decisions

- 单机 AI，默认八人身份军争，可选人数；不新增联机、账号、付费或远程部署。
- 用户后续明确四人局为 2v2：一、四号位同队，二、三号位同队；玩家固定四号位，队友与敌方均明示。其他人数保留身份局。
- 新增三人斗地主，可自选地主或农民；使用原生休闲模式和十周年版飞扬。跋扈在准备阶段摸一张、出杀次数加一；地主体力及上限加一，保留原生武将例外与胜负规则。
- 直接复用上游事件结算、卡牌、技能与 AI，禁止用随机扣血代替技能。
- 新增原创墨色、朱红、铜金视觉入口，提供选将、势力/包筛选、技能搜索、技能详情、启动真实对局和返回入口。
- 保留上游许可证、来源与现有游戏入口，新增定制入口 `apps/core/sgs.html`。
- 十周年专属包、通用基础包、其他版本必须明确分类。`dc_` 前缀不能作为唯一版本判断。
- 武将与技能清单由源码生成，可追溯至包、ID、技能定义和上游提交；报告分别显示源码收录、定义解析、行为验证状态。
- 全量的官方分母目前尚无完整可信清单；先保留“官方全量待逐项核验”状态，绝不显示虚构的 100% 覆盖。
- 本地检出省略移动端、音频和角色画像的大体积原文件；按用户后续要求，将现有网络/上游画像压缩为本地 WebP，覆盖全部收录 ID，关闭缺失音效。不修改技能机制。
- 用户追加要求卡牌出牌语音：在 SGS 目录保留轻量本地卡牌语音包，覆盖出牌、打出响应与技能转化；未提供的武将语音和背景音乐继续关闭。
- 按用户要求，所有单机模式禁用木牛流马；使用原生禁牌配置，从实际牌堆及可生成牌名列表排除。
- 当前没有用户自己的远程仓库。只本地提交，严禁推送上游 origin。

## Goals

- 用户能搜索大量真实武将、阅读对应技能并实际进入 AI 身份对局。
- 十周年已收录的武将与技能有可重复生成的机器清单。
- 错误版本、缺失技能、未验证状态可被识别，后续 Ralph 能继续补齐。
- 实际浏览器验证选择武将、开局、出牌/结束回合、AI 行动和返回入口。

## Non-Goals

- 联机、商城、官方登录、官方私有服务、美术/语音逐像素复制。
- 不将本次入口适配的完成声明为十周年全量行为验证完成。

## Functional Requirements

- FR-1: 所有对局操作调用上游事件/技能系统。
- FR-2: 版本 ID 不合并；十周年同名武将与 OL/手游变体分开。
- FR-3: 本地偏好仅存本机；不要求登录或 API key。
- FR-4: 模糊/待核验分类明确显示；覆盖率分母未知时不显示百分比。
- FR-5: 应能在 Windows 上用启动脚本运行，不要求用户理解 pnpm monorepo。

## Validation

- 运行 `node scripts/sgs/build-catalog.mjs`、`node --test tests/sgs/*.test.mjs`（对应文件建立后）。
- 使用 `node --check` 检查新增 JavaScript；新增 TypeScript 则运行专用 tsc 配置。
- 浏览器验证 `http://127.0.0.1:8081/sgs.html` 和真实游戏页面。
- 检查请求/控制台中的阻断错误并修复；UI 用截图检查。
- 单故事完成后更新 passes、进度日志并本地提交；无远程推送。

## Risks / Open Questions

- 官方持续增将和改技能，当前无已确认官方全量分母；需要固定核验日与版本。
- 上游包含 OL/手游/线下变体和社区改动；分类和规则一致性需要独立核验。
- 全量技能组合爆炸，源码包含不代表每一场景都正确。
- 大体积素材不在当前稀疏检出中；入口与牌桌必须有可读后备表现。
- 不确认全量对账完成前，US-006 必须保持 false，并在最终交付中说明。

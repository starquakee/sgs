# 轻量头像与图片来源

选将页、详情页和真实牌桌共用 `apps/core/sgs/portraits.json`。每个收录武将 ID 保留独立映射；同一图源去重保存于 `apps/core/sgs/portraits/`。默认图片为 192×256 WebP，每个文件最多 8,192 字节，全部画像总量不超过20MiB。游戏只读取本地文件，不向图片来源站点发送请求，也不需要 Python。

这是2026-10-05确认的轻量清晰度升级：从已归属原图重新压缩，不放大原来的96×128输出图。每张新版图记录原图尺寸及SHA-256；原图不可取得时保留经哈希与解码验证的旧图，在清单`upgradeFallbacks`列出图源、文件及原因。旧同人物替代与测试剪影的含义不变。

## 来源与例外

- 大部分图片来自 [Noname 固定提交](https://github.com/libnoname/noname/tree/7fcf23ed54d8a7ce2b49ae2c15a054123891a52a/apps/core/image/character)。清单逐项记录原图路径、提交、文件大小和 SHA-256。
- 34 个尚无独立原画的版本使用同一人物的上游画像，映射见 `scripts/sgs/portrait-aliases.json`。不把其他人物当作该武将。
- 补充网络图的页面、直链及身份依据见 `scripts/sgs/portrait-sources.json`。崔芷来自十周年官网；小空来自 AIR 角色讨论页面；韩玄、吕壹使用光荣特库摩《三国志14》同人物画像；孙和、张臶使用同人物资料画像。这些资料画像在详情页有说明。
- 邓晚棠、刘盼兮的公开测试实战可见通用女性剪影；陆文漪资料页无画像，未找到可独立核验的实战卡图。经用户于 2026-10-03 明确同意，三位先使用已有通用测试形象。前两位标注“公开测试形象 · 剪影”；陆文漪标注“测试剪影暂代 · 独立画像待补”。不宣称三者是已发布的正式立绘。
- 本次交付未使用 AI 生成图片。下载的原始素材、研究视频和截图不进入游戏包。

代码继续遵循仓库 GPL-3.0；图片作品的权利属于各原作者/权利人，保留来源不意味着图片版权转为本地适配者所有，也不代表这些不同来源的美术都按 GPL 授权。

## 重建

需要 Node 22、Python 3 和 Pillow；日常构建直接复制已提交的小图。

```powershell
node scripts/sgs/prepare-portraits.mjs
python scripts/sgs/build-portraits.py --download
node --test tests/sgs/portraits.test.mjs
python -m unittest discover -s tests/sgs -p test_portrait_builder.py -v
```

规划器读取固定上游提交的文件树和武将元数据，再应用显式同人物映射及额外来源。下载器在内存中缩小图片，原图不落盘；已存在的当前编码版本直接校验复用。先在忽略的构建缓存中准备新图，完整清单通过逐图解码、哈希、尺寸及总量检查后切换清单，再删除不再引用的旧生成图及重复暂存图。不会递归删除目录，也不会清理不属于旧清单的未知文件。

不带`--download`可以离线校验和复用当前画像；带该参数会重试上次保留旧图的图源。既无新版也无有效旧图时，默认失败并保留现有清单。`--allow-incomplete`仅将不完整诊断报告留在缓存，不会安装缺图清单，不能用来声明验收完成。

编码版本与裁切参数参与文件名计算；调整后重建并复核，不应先删有效旧图。Node测试检查全部ID映射、来源、单图/总量预算、哈希与目录一致性；维护用Python测试验证编码、可靠回退及替换前验证，构建器实际解码每张图。规则/技能的完整核验仍属于US-006。

## 2026-10-05 升级结果

2,563个武将版本映射到2,491张去重画像，全部192×256；总计16,607,254字节（15.84MiB），最大单图8,190字节。本次没有旧图回退，来源/替代关系/剪影说明均未改变。游戏包和完成后的暂存区都不保留双份图片。

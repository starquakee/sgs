# 武将官方数字评分

2026-10-05按用户确认的“游戏内武将评分（数字分数）”实现。卡片和详情显示十分制分数，支持升序、降序与恢复默认顺序。默认显示综合分，更多筛选可切换八项身份/玩法分数；详情可查看全部九项与数据日期。分数与稀有度、社区排行无关。

## 数据来源

- 产品：游卡《三国杀十周年／一将成名》。[官方入口](https://x.sanguosha.com/)。
- [公开版本清单](https://web.sanguosha.com/10/pc/versionConf.js)记录时间为`2026-10-01 14:47:58.691`，本地于2026-10-05获取。这是固定快照，不是实时联网评分。
- 原始分数字段：[Config.sgs](https://web.sanguosha.com/10/pc/res/config/Config.sgs?v=8b1229df)中的`GameGeneralConfig.sgs / GeneralConf[].ModeScore`。使用`GeneralID`连接角色表及初始技能表，仅保存姓名、势力、技能名、ID和数值等匹配事实。
- 官方客户端的`MSModeType`、`MSFIgureType`、`GeneralInfoVO`及评分面板用于确认字段含义和0至10显示边界。综合分直接取`ruleType=5`，不计算平均值。原始包、客户端包及公开解码器的URL和SHA256均保存在`scripts/sgs/official-ratings-source.json`。
- 快照包括813个有评分且属于身份/2v2角色范围的官服ID。排除了纯PVE/国战条目；不把不可获得标记当作无评分。普通构建使用已保存的事实JSON，不联网、不执行官服客户端。

## 版本匹配边界

当前681个本地武将版本匹配到681个官服ID。默认常用786个可见版本中另有105个未匹配；其他平台/参考包继续不套用十周年评分。完整名册仍保留2563个源码版本。

自动匹配限定在九个目标源码包，要求完整版本姓名、势力、基础体力上限、初始技能名称相同且官服候选唯一。“新杀”仅是本地显示前缀；标、界、神、谋等实际版本区别必须保留。明确的异名及授予技能例外列入`official-rating-map.json`并注明依据。只匹配评分展示，不代表技能代码已经逐条行为验证。

- 标曹操为5分、界曹操为6分，分别对应官服16和75。
- 神黄忠综合9分，地主10分、农民9分；威孙策综合9分、地主8分。
- 旧神张辽的技能集合不同于新版，保留未匹配。黄权、庞山民、郭淮的本地基础体力上限与官服不同，亦不套用当前评分。
- 神关羽官服201的武神3645为红桃杀伤后摸牌，武魂3646在造成/受到伤害时均加梦魇；只映射`xianding:dc_shen_guanyu`。`extra:shen_guanyu`虽技能同名，但效果不同，排除。
- 辛宪英官服528的忠鉴776/才识777为伤害触发效果与摸牌花色判定，只映射`xianding:re_xinxianying`，不借给旧版`yijiang:xinxianying`。
- 雷铜、吴兰等同名同技能且有多个官服候选、分数不同的条目保持未匹配。体验角色、跨平台变体和未收录新将不能凭同名借分。
- 验证器拒绝两个本地版本竞争同一个官服评分ID，要求先审查实际技能差异再决定映射。

分数空缺显示“评分待收录”，排序时始终置后，同分保持原分包/最近使用顺序。恢复“默认顺序”不会更改记录。筛选、翻页、排序保留出战武将及模式；只在确认出战时写最近使用。偏好损坏或不可写时可继续使用当前页面。名册加载期间排序控件禁用，避免覆盖已保存口径。

## 生成与验证

`node scripts/sgs/build-lobby.mjs`依据固定评分快照和映射策略生成`apps/core/sgs/roster.json`，保持原始`catalog.json`、武将ID及技能实现不变。维护用`import-official-ratings.mjs`仅接收三个SHA256相符的已核对数据文件；它们在忽略的研究缓存中，不随仓库分发。更新官服快照必须重新核对版本、哈希、字段与版本映射，不能悄悄替换。

173项回归通过。新增测试覆盖官方分项、重复字段和显示边界、版本排除、竞争版本拒绝、全名册重生成一致性、零分/缺分/非法分数、稳定升降序、实际排序事件、组合筛选、翻页复位、最近顺序恢复、持久化/坏存储/慢加载和精确版本开局交接。
